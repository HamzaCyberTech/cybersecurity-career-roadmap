# Cybersecurity Roadmap

This repository documents my journey through a structured cybersecurity learning path, inspired by the Awesome Cyber Security University roadmap.  
It includes hands-on labs, TryHackMe modules, and professional notes covering:

- 🔹 Fundamentals: Linux, networking, research, pentesting basics
- 🔹 Tooling: Nmap, Hydra, Metasploit, Sublist3r, tmux
- 🔹 Web Exploitation: OWASP Top 10, Juice Shop, LFI/Injection labs
- 🔹 Privilege Escalation: Linux & Windows Privesc arenas, CVE-focused labs
- 🔹 Reverse Engineering & Pwn: Ghidra, Radare2, pwntools, ELF reversing
- 🔹 Red Teaming: Recon, engagements, methodology
- 🔹 CTF Practice: Beginner to intermediate boot‑to‑root challenges

---

## 🎯 Purpose
- Build a **portfolio of practical cybersecurity skills** aligned with industry standards.  
- Prepare for **eJPTv2 certification** and entry‑level penetration testing roles.  
- Showcase **professional documentation** for interview readiness.  

---

## 📌 Note
All labs are completed in controlled environments (TryHackMe, HackTheBox, custom VMs). Sensitive data is excluded. This repo is intended as a **learning portfolio** and not for malicious use.
