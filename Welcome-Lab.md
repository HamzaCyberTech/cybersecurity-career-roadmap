# Welcome - TryHackMe Lab

## Overview
Completed the Welcome lab to understand how the TryHackMe platform works and how to interact with virtual machines in a controlled environment. The objective was to get familiar with the lab interface, AttackBox, and workflow for completing cybersecurity challenges.

## Tools & Techniques
- TryHackMe AttackBox
- VPN connectivity setup
- Interactive lab environment navigation
- Task completion and flag submission

## Steps
1. Connected to the TryHackMe environment using the AttackBox and VPN.
2. Explored the lab interface, including task lists and progress tracking.
3. Practiced submitting answers and flags to verify understanding.
4. Reviewed how to save rooms, track achievements, and manage learning paths.

## Key Findings
- Gained familiarity with the TryHackMe platform and its workflow.
- Learned how to interact with virtual machines safely.
- Understood the process of completing tasks and submitting flags.
- Established a baseline for progressing into more advanced labs.

## Lessons Learned
- The Welcome lab is essential for building confidence in using the platform.
- Proper environment setup ensures smooth execution of future labs.
- Understanding the workflow early reduces errors and improves efficiency.
