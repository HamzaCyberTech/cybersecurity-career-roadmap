# OpenVPN - TryHackMe Lab

## Overview
Completed the OpenVPN lab to learn how to securely connect to virtual private networks (VPNs). The objective was to establish a stable connection to TryHackMe’s lab environment, enabling safe and isolated penetration testing practice.

## Tools & Techniques
- OpenVPN client configuration
- `.ovpn` configuration files
- Command-line VPN connection management
- Network interface verification
- Troubleshooting connectivity issues

## Steps
1. Downloaded and configured the `.ovpn` file provided by TryHackMe.
2. Established a VPN connection using the OpenVPN client.
3. Verified connectivity by checking assigned IP addresses and routes.
4. Tested access to lab machines through the VPN tunnel.
5. Documented troubleshooting steps for common issues (firewall, permissions, DNS).

## Key Findings
- Successfully connected to TryHackMe’s isolated lab environment.
- Verified secure tunneling of traffic through the VPN.
- Identified common issues such as firewall blocks and DNS resolution errors.
- Ensured stable connectivity for subsequent penetration testing labs.

## Lessons Learned
- VPN connectivity is a critical prerequisite for hands-on cybersecurity training.
- Proper configuration and troubleshooting skills are essential for reliable lab access.
- Understanding VPN tunnels reinforces knowledge of secure remote networking.
